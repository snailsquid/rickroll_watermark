# Goal
Projek ini bertujuan untuk mananamkan watermark pada alur JPEG encoding. 
Watermark yang ditanamkan merupakan sebuah video rickroll.
Tujuan repository owner adalah untuk belajar bahasa Go dan encoding.
# Constraint
Projek ini hanya sebagai metode belajar. Kode seluruhnya dibuat tanpa LM.
Size image yang digunakan berupa fixed agar mempermudah.
Size video yang digunakan juga fixed.
Tujuan merupakan pembelajaran encoding sehingga variabel yang tidak terlalu berpengaruh akan dihilangkan.
LM hanya digunakan sebagai teman tanya jawab, bukan sebagaig pembuatan kode.
